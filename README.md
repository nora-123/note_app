# Note App | DEPI Project 📝

A professional, high-performance note-taking application built with **Flutter**. This project demonstrates clean architecture, reactive state management, and robust local persistence, developed as part of the **Digital Egypt Pioneers Initiative (DEPI)** training program.

## ✨ Features

- **Full CRUD Support**: Effortlessly create, read, update, and delete notes.
- **Local Persistence**: Integrated with **Sqflite** for high-speed, reliable offline storage.
- **Modern State Management**: Uses **Cubit (Bloc)** to ensure a predictable and scalable data flow.
- **Premium UI/UX**:
  - Material 3 Design System.
  - Custom typography with **Google Fonts (Poppins)**.
  - Elevated Card-based layouts for better readability.
  - Interactive micro-interactions and smooth navigation.

## 🛠️ Technical Stack

- **Framework**: Flutter (Dart)
- **State Management**: Flutter Bloc / Cubit
- **Database**: Sqflite (SQLite for Flutter)
- **Styling**: Google Fonts, Material 3, Custom Card Decorations
